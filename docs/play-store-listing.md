# Ficha Play Store - FactuDarwin

## Nombre

FactuDarwin

## Descripcion corta

Facturacion electronica, ventas, inventario y cobros para negocios en Ecuador.

## Descripcion completa sugerida

FactuDarwin ayuda a pequenos negocios, comercios y profesionales en Ecuador a gestionar ventas, clientes, productos, inventario, cuentas por cobrar y comprobantes electronicos desde una app movil.

Con FactuDarwin puedes registrar clientes, productos y ventas, emitir facturas electronicas, crear notas de venta, proformas, notas de credito y guias de remision, manejar cobros a credito, generar recibos termicos y consultar reportes utiles para la operacion diaria.

Funciones principales:

- Facturacion electronica conectada al SRI.
- Ventas, notas de venta y proformas.
- Clientes y productos con busqueda rapida.
- Inventario y kardex con paginacion por bloques.
- Cuentas por cobrar, abonos y recibos.
- Multiples establecimientos y puntos de emision.
- Sincronizacion entre dispositivos autorizados.
- Reportes comerciales y de caja.
- Soporte por WhatsApp.

La aplicacion esta pensada para negocios que necesitan una herramienta practica, ordenada y lista para operar con datos reales, manteniendo control por empresa, usuario y establecimiento.

## Seguridad de datos - guia para Play Console

Completar segun la configuracion final de produccion:

- Datos personales: nombre, correo, telefono, direccion, identificacion.
- Informacion financiera/comercial: ventas, facturas, cobros, productos, inventario.
- Archivos: logotipo y certificado electronico cargado por el usuario.
- Datos de diagnostico: logs tecnicos, errores, eventos de sincronizacion.
- La app usa camara para escaneo de codigos.
- Los datos se transmiten por HTTPS.
- Los datos se usan para operar el servicio, sincronizar, facturar, dar soporte y cumplir procesos tributarios.
- No declarar venta de datos personales si el servicio no vende informacion a terceros.
